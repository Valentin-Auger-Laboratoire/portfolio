Générateur de configuration Cisco et VyOS

Décrivez le site ou le pare-feu : l'outil vérifie les données (adresses, chevauchements, ports, numéros de VLAN, règles) puis écrit la configuration à coller dans l'équipement. Aucun mot de passe n'est demandé : un marqueur <MOT_DE_PASSE> est laissé à sa place.
