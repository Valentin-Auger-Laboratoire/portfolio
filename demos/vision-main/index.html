Démo interactive · vision par ordinateur

Suivre la main, puis construire des cubes avec des gestes

La webcam détecte les 21 points de chaque main en temps réel. Étape 1 : touchez le bouton QUITTER du bout de l'index. Étape 2 : pincez le pouce et l'index pour poser des cubes, fermez le poing pour effacer.

Version web de démonstration (JavaScript, MediaPipe Hands) qui reprend la logique des scripts Python du projet : voir le code Python ↗

La caméra ne s'allume qu'après ce clic. Le modèle de la main (≈ 8 Mo) se charge une seule fois.

Commandes

Index sur QUITTER
Le bouton passe au vert, puis la caméra s'arrête au bout de 0,3 s.
Clic sur QUITTER ou touche Q
Arrêt immédiat.
Viser avec l'index
Un cube fantôme suit le bout de l'index, aimanté sur une grille.
Pincer pouce + index
Pose un cube. Un seul cube par pince : relâchez pour en poser un autre.
Avancer ou reculer la main
Change la taille du cube (profondeur simulée).
Fermer le poing
Efface le dernier cube.
Z C Q
Annuler, tout effacer, arrêter.

Les images de la caméra sont analysées dans votre navigateur. Rien n'est enregistré ni envoyé.
