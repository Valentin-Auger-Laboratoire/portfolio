Démo interactive · vision par ordinateur

Suivre la main, construire en 3D, lire les signes et le visage

La webcam détecte les 21 points de chaque main et les 478 points du visage en temps réel. Cinq étapes : un bouton touché du doigt, des cubes posés par pince, un vrai monde 3D construit avec les deux mains, l'alphabet des signes lu lettre par lettre, puis l'humeur lue sur le visage.

Étapes 1 et 2 : portage web des scripts Python du projet. Étapes 3 à 5 : ajoutées en 2026, écrites directement pour le web (JavaScript, MediaPipe Hands et Face Landmarker). voir le code ↗

La caméra ne s'allume qu'après ce clic. Les modèles (main ≈ 8 Mo, visage ≈ 4 Mo) se chargent une seule fois.

Apprendre mes signes

Lettres reconnues

J et Z se font avec un mouvement : elles ne sont pas reconnues. Les modèles des lettres viennent d'une main de synthèse : les lettres proches (A, S, E, M, N, T) peuvent se confondre avec une vraie main. Enregistrer ses propres exemples corrige la plupart des erreurs.

Humeur

Indices du visage

Reconnaissance d'expressions, pas d'identification : le modèle ne sait pas qui vous êtes. L'humeur est déduite par des règles sur 52 coefficients d'expression (sourire, sourcils, bouche…). Une expression n'est pas une émotion : c'est une démonstration, pas un diagnostic.

Les images de la caméra sont analysées dans votre navigateur. Rien n'est enregistré ni envoyé.
